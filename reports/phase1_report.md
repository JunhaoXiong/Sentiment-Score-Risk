# Phase 1 报告：情绪数据管线（描述性结果）

所有数字来自 `scripts/phase1_analysis.py` → `reports/phase1_summary.json`。本阶段只做描述，不对风险模型下结论（那是 Phase 2）。

## 1. 数据
| 数据 | 实际得到 |
|---|---|
| GDELT 主查询 `"stock market" sourcecountry:US sourcelang:english` | 3,266 个 UTC 日（2017-01-01 至 2025-12-31，无缺失），每日平均语调 + 匹配文章数（日均 425 篇） |
| GDELT 敏感性查询 `theme:ECON_STOCKMARKET` | API 持续限流（HTTP 429），后台仍在重试；未进本报告 |
| FOMC 声明 | 74 篇（2017–2025；2020 年含 3/3、3/15 两次紧急声明），正文中位数 319 词 |
| SPY / VIX / VIX3M / VIX9D | Yahoo 2012–2025，无缺失 |

原本计划把 GDELT 主题查询当主查询，因限流改成关键词查询当主查询。

## 2. 关键设计（已实现并有测试）
- **时点规则**：时刻 τ 发布的信息只能用于第 t 天的预测，前提是 τ ≤ 第 t−1 天美东 16:00。GDELT 的日数据按 UTC 切分，UTC 日 d 结束于美东 19/20 点，已过收盘，所以**往后推两个交易日才生效**（例：周一的新闻 → 周三）。周末的几天按文章数加权合并。FOMC 声明一律按发布日 16:00 处理（实际是 14:00，故意偏保守）。
- **标准化**：z_t = (x_t − 过去 250 个交易日均值) / 过去 250 天标准差，不含当天；至少 120 天才出值，所以 z 从 2017-06-27 开始，共 2,128 个交易日。
- **LM 词典**：score = (正词数 − 负词数) / 总词数（即你的设计），另外算了不确定性词占比。不处理否定词（"not strong" 会算作正面），这一点如实保留。
- 测试 16 个：对齐边界（收盘前后 1 秒、周日紧急降息、夏令时切换）、随机 500 个发布时点都不早于可用时点、z-score 改动未来不影响过去、词典计数、解析器。

## 3. 描述性结果
**语调本身偏负**：日均语调 −0.61，82% 的日子为负。这验证了要用相对滚动基线的 z，不能直接用原始值。

**与风险变量的相关（z 为当天生效值）**

| 变量 | corr(z, ·) |
|---|---|
| 当日收益 r | −0.02（方向几乎不可预测） |
| 当日 \|r\| | −0.25 |
| 未来 5 日已实现波动 | −0.32 |
| 昨日 VIX | −0.30 |
| VIX/VIX3M（>1 表示倒挂） | −0.39 |

情绪对**波动**有信息，对**方向**基本没有。这支持风控版优先、期权版做波动率而不是方向的路线。

**滞后结构（`figures/leadlag.png`）**：z 和**过去**的 \|r\| 相关更强（k=−2 时 −0.30），和**未来**的 \|r\| 相关弱一些（k=+1 时 −0.24）。说明新闻语调主要在**反应**已发生的下跌，而它对未来的相关有很大一部分来自波动聚集。Phase 2 必须控制滞后收益，GARCH 本身就控制了。

**在 VIX 之外有没有增量（HAC 标准误，同一批交易日）**

| 被解释变量 | 只用昨日 VIX：R² | + 情绪 z：R² | z 的 t 值 |
|---|---|---|---|
| 当日 \|r\| | 0.310 | 0.319 | −4.4 |
| 未来 5 日已实现波动 | 0.515 | 0.528 | −4.2 |

增量在统计上显著，但很小（R² 只增加约 0.01）。这是一个预告，不是结论：这里没有控制滞后 \|r\|，也没有做样本外检验。

**最差 1% 的日子（22 天）**：这些天的平均 z 为 −1.09，其余日子为 +0.01。不过这些天大多集中在危机期间，本身就和波动聚集重叠。

**危机窗口（`figures/crisis_windows.png`）**

| 事件 | SPY 最差日 | z 首次 < −2 | z 最低日 |
|---|---|---|---|
| 2018-02 Volmageddon | 02-05 | 02-07（晚于暴跌） | 02-07 |
| 2020 COVID | 03-16 | 02-26（在主跌段之前，但在 2/24 第一次大跌之后） | 03-02 |
| 2022-06 加息 | 06-13 | 未跌破 −2（最低 −1.94） | 06-15 |
| 2025-04 关税 | 04-04 | 03-21（早于暴跌） | 04-09 |

只有 COVID 和 2025 关税这两次是"提前或贴近"的预警，其余两次是事后反应。另有明显的误报：2019-09-06 的 z 达到 −4.25，但当时市场并没有出事。

**FOMC（LM）**：74 篇，净分数均值 +0.6%。最负一篇是 2022-06-15（加息 75bp），最正一篇是 2024-06-12，不确定性词占比最高的是 2024-09-18（降息 50bp）。生效日 FOMC 净分数和 \|r\| 的相关为 −0.05，在 74 个点上没有可用信号。FOMC 更适合当事件标记，不适合当日频风险因子。

## 4. 局限（会写进最终报告）
1. GDELT 的语调是 GDELT 自己的词典，不是 LM；GDELT 不提供正文。
2. UTC 日切分带来约 1 天的额外滞后。小时级数据可以消除它，但 API 限流让 9 年的小时数据实际下载不了。
3. 2017 年后可用于检验的危机只有 4 次左右，检验力低。
4. LM 词典用的是 `pysentiment2` 自带的旧版本，最新官方版需要访问 Google Drive。

## 5. 对 Phase 2 的含义（待你决定）
- 情绪 z 起点是 2017-06。如果滚动窗口 W=1000，样本外要到 2021 年才开始，会错过 COVID。可选：W=500（样本外约从 2019-06 开始，覆盖 COVID），或扩展窗口。
- 外生变量形式：δ·max(0, −z_{t})，只让负面情绪推高方差。
- 必须设的对照组：GJR、GJR+VIX、GJR+VIX+情绪。
