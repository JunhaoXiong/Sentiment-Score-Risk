# Phase 2c：是不是"两天滞后"害了情绪信号？（时点上界检验）

数字来自 `scripts/phase2c_timing_bound.py` → `reports/phase2c_summary.json`。

## 为什么没做小时级数据
- GDELT 的 DOC API 只有窗口足够短时才给日以下的粒度：14 天的窗口返回的仍是日数据，7 天的窗口请求一直没成功，所以没能确认。
- 从这个云环境发出的短窗口请求连续 25 分钟以上被限流（HTTP 429），一次都没成功。9 年的小时数据需要约 1,000 次请求，实际下载不了。
- API 对日数据会忽略 `timezoneadj` 参数，返回值和不调整时完全相同，所以也不能靠平移时区把切分点挪到收盘。

## 改做上界检验
- **诚实版（Phase 2）**：UTC 日 d 的新闻要到下一交易日收盘后才可用。
- **上界版**：假设 UTC 日 d 在当天收盘时就已完整可用，即提前一个交易日。这会**泄露**收盘后 3–4 小时（美东 16:00–20:00）的新闻，结果偏向对情绪有利，只能当上界，不能当真实信号。
- 道理：如果连这个偏乐观的版本都打不过 GJR / GJR+VIX，那么正确按收盘切分的小时级信号也不会更好。

## 结果（同一批样本外日：2019-06-25 至 2025-12-31，共 1,625 天）
| 模型 | 99% 突破（期望 16.3） | Kupiec p | 条件覆盖 p | 99% tick ×1e4 |
|---|---|---|---|---|
| M0 GJR | 27 | 0.014 | 0.031 | 4.065 |
| M1 +VIX | 25 | 0.043 | 0.090 | 4.037 |
| M3h +VIX+情绪（诚实版） | 27 | 0.014 | 0.038 | 4.036 |
| M3b +VIX+情绪（上界版） | 24 | 0.071 | 0.130 | 3.989 |

- **全样本估计**：情绪系数 δ 在诚实版和上界版里**都等于 0**。
- **DM 检验（99%）**：上界版对 GJR+VIX 是 −1.43（p = 0.15），诚实版对 GJR+VIX 是 −0.04（p = 0.96）。两个都不显著。
- **相关**：和当日 \|r\| 的相关，上界版 −0.29，诚实版 −0.25；和次日 \|r\| 的相关，上界版 −0.245，诚实版 −0.238。提前一天几乎没有增加对未来的信息，多出来的部分主要是"当天已经发生的事"。
- **2025 关税冲击前 10 天**：99% VaR 相对 GJR+VIX 的上调，诚实版 +3.3%，上界版 +6.1%。

注：样本起点比 Phase 2 少了 3 天，重新估计的日期也随之平移，所以诚实版的突破数和 Phase 2 有 ±1 的差别。

## 结论
时点不是主要原因。即使让情绪信号提前一个交易日，还额外偷看了几小时收盘后的新闻，它在 GARCH 框架里仍然没有显著增量。Phase 2 的否定结论在时点上是稳健的。真正的瓶颈是这个新闻语调指标本身在追随市场。要想有增量，可能需要换成更"前瞻"的文本，例如美联储会议纪要的不确定性、财报电话会，或者期权隐含信息本身。
